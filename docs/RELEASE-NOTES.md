# 0.1.0-alpha.1 — unpublished development preview

This version is built locally and is not yet a public release. Local artifacts may be rebuilt while unpublished; a published version must never be replaced.

The preview includes five framework NuGet packages, a full-stack template package, and four npm packages. The sample contains CRM metadata CRUD and a Sales quote aggregate, local Identity and external OIDC browser modes, opt-in bearer API scopes, separate database migration assemblies, and Atlas workspace integration.

The starter includes a taskbar-based shell, avatar account dialog with password change, and an integrated forms-and-controls showcase available from home and Start. A tested [module-authoring walkthrough](MODULE-AUTHORING.md) covers integrating generated CRUD, provider migrations, permissions and menus into that starter. Follow [STARTER-QUICKSTART.md](STARTER-QUICKSTART.md) to generate a separate application from unpublished local packages.

Recent changes include typed OData reads, decimal-string inputs, custom field components/validators, nested permission-aware menus, guarded close-all, detached-save isolation across session changes, active-task first-invalid-field focus, scaffold previews/source hashes and generated authorization tests. Local recovery/confirmation forms and a private development mail sink are included. Resource-spec generation supports seven scalar field types with backend/frontend tests and separate user-owned validation hooks. Explicit manifest-based regeneration preserves custom rules, refuses conflicts and retains rollback backups. Template substitution tokens are delimited to avoid rewriting framework type names.

Package verification restores actual local artifacts into an isolated template and NuGet environment. It builds/tests both backend and frontend for all four generated database/auth combinations and runs generated module tests. Its report identifies artifact SHA-256 hashes. Separate CI jobs also verify real migrations, Identity, generated CRUD and installed-starter runtime on PostgreSQL and SQL Server. The live Keycloak verifier adds real-provider role mapping, draft/API authorization and full logout checks; its protocol tests are separate from browser rendering checks.

Exact configured versions and qualification limits are listed in [COMPATIBILITY.md](COMPATIBILITY.md). Remaining release gates are tracked in [ACCEPTANCE.md](ACCEPTANCE.md). The public repository and MIT license are confirmed. Broader browser/accessibility coverage and additional identity providers remain unqualified; registry ownership, provenance and publication are deferred by the owner. This preview is not a production-ready ERP application or multi-tenant platform.
